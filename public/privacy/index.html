Privacy Notice

How the Healthcare Governance Commons handles submitted information.

The short version: The Commons is a working prototype built by one person. It does not store what you type into its tools, and the parts that would collect information from visitors are paused. Do not enter patient information anywhere on this site.

What is live and what is paused

  • Live: the governance map, node pages, document library, Community Weaving series, and tools that answer from what you type (Validation Protocol Generator, ROI Assessment, Governance Assessment, Disagreement Unpacker, Container Health Check, Charter Builder, node synthesis, Facetious Collaborator).
  • Contributions: each node page lets you suggest a source, a tool, or a question, or add a practitioner note. Nothing is published until it's reviewed by hand.
  • Paused: document upload in the Validation Protocol Generator, and registrations and introduction requests in the Peer Challenge Registry. These would collect files or contact details, and they stay closed until someone is accountable for securing them.

What happens to what you type

  • AI-assisted tools send your text to Anthropic's API to generate a response, through this site's server. The Commons does not save your text or the response. Anthropic handles the request under its API terms.
  • Validation Protocol Generator sends your answers to this site's server to assemble the protocol. Nothing is saved; the PDF is built in your browser.
  • Contributions are stored for review: the link or text you send, the node it's for, and the time. For practitioner notes, the name and role you choose to publish, if any. No email, contact details, or network address is stored with a contribution. Before review, each contribution is read by two AI reviewers (through Anthropic's API) that recommend accepting or rejecting it; a person makes every final decision. Rejected contributions are deleted; the site keeps only counts (how many of each type were submitted, accepted, or rejected, and the website domain of suggested links), never the content. Accepted ones are published on the node page.
  • Usage limits. To stop the AI tools from being abused, the site keeps a count of requests per network address. Each count is deleted automatically after about an hour.
  • Hosting. The site runs on Vercel, which keeps standard request logs.

Not for patient information

None of these tools are designed to receive protected health information (PHI) as defined under HIPAA, and there is no PHI detection on typed input. Describe systems and situations, not patients.
