Local Validation Kit

Test a clinical AI model on your own past patients before you trust it. Rules label most cases automatically. A person reviews only the cases the rules can't decide, plus a blind sample that checks the rules themselves. You get the four counts the Validation Protocol Generator needs, with confidence intervals and numbers for each patient group.

Paused for review. The kit isn't open for use yet. Before any hospital relies on it, the sepsis rules need sign-off from a clinician and the math needs a check by a statistician. It will open here once both are done. The Validation Protocol Generator still works with counts you already have.
Your file never leaves this browser. The page reads it on your computer and sends nothing anywhere. That's enforced, not just promised: the page's security policy blocks all network requests. Still, use a study ID, not an MRN, and leave out names and dates. The kit doesn't need them.
For your security team
  • Run it offline. Download the kit as one file and run it from your own computer. After that, nothing on this website can change it, even if the website were ever compromised.You're running the offline copy. Nothing on the website can change it. Download the offline kit.
  • Check the fingerprint. The offline file's SHA-256 should be see local-validation-kit-offline.html.sha256. On a Mac: shasum -a 256 local-validation-kit-offline.html. On Windows: certutil -hashfile local-validation-kit-offline.html SHA256. A different value means the file isn't the one published here: don't use it.
  • No network. The page's Content-Security-Policy sets connect-src 'none'; the offline file also sets default-src 'none', so it can't load anything at all.
  • No third-party code. Three small script files written for the Commons, no libraries.
  • Rule packs can't run code. They're plain data, checked before use. A bad pack can give wrong labels, which is why packs show their clinician sign-off status.
  • Downloads are spreadsheet-safe. Cells that start with = + - or @ are neutralized, so nothing in a loaded file can run as a formula when a download is opened in Excel.
  • One thing the page can't control: browser extensions. An extension with permission to read pages can read this one too. Use a browser profile with no extensions, or the managed browser your security team already locks down.
  • Source: the kit's code is public in the Commons repository on GitHub (public/local-validation/).

Earlier audit cases stay as reviewed labels but no longer count toward rule accuracy, so the new number is a clean test of the fixed rules.
