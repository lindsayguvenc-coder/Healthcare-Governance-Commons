About the agent

1. What does one run produce?

Pick every type. The data type decides which statistics work.

Examples

Grocery agent: a choice from a set (an aisle per item), pass/fail for the whole run, and tool calls (it places each item with a call).

Discharge drafter: free text, which a reviewer grades 1–5.

Slide-screening agent: an image with suspect cells circled, plus a pass/fail call.

2. Is there a known right answer?

Accuracy needs a reference. Without one you can only measure consistency and change.

Examples

Grocery agent: answer key, set by one person who admits she's always lost in grocery stores. Two items turned out contested (oat milk, sunflower seed butter) and became drift-only.

Discharge drafter: a judge model scores it. Not yet checked against clinicians.

3. What happens when it's wrong?

Sets how strict the cutoffs and rules need to be.

Examples

Grocery agent: harm. An allergen shelved as allergen-free, or chicken left out of the cold aisle.

Discharge drafter: harm. A dropped medication change.

4. What will you watch?

A fixed control isolates the agent. Live traffic shows real use but mixes in changes to the inputs.

Examples

Grocery agent: a fixed control. The same 11-item list every run.

Discharge drafter: both. 30 fixed charts weekly, plus a sample of real drafts. No moving average yet.

A ticket-routing agent: live only, with a 200-ticket moving average of the share sent to billing.

5. What change worries you?

The drift card checks all four kinds of change either way. Your picks are marked, so you can see which gaps you already knew about.

Examples

Grocery agent: a model swap and a silent update.

Discharge drafter: all four, including a new patient population.

7. What must never happen?

Never-events reject a run whatever its score. One per line.

Examples

Grocery agent: peanut butter in the allergen-free aisle. Any cold item in a warm aisle.

Discharge drafter: a medication change left out. A new allergy left out.

9. Where did those numbers come from, and does your test set sit near them?

A cutoff is only as good as its source. A test set that's too easy can't show drift.

Examples

Grocery agent: expert judgment. No: 100 of 100 baseline runs passed, so the control sits at the ceiling.

Discharge drafter: guideline-based. Yes: complex charts score 3–4.

Levey-Jennings rules, for numbers

For any output you chart with a mean and SD: a numeric result, output tokens, an average grade. Set each rule to off, warn or reject. Detection and whole-set numbers come from simulating 40,000 runs on one fixed set of random draws, so every setting is compared on the same data. False rejections for each rule alone are exact.

These numbers assume roughly normal results, independent runs, one control result per run, and fixed sampling settings (temperature and the like) so repeats are true repeats.

They also assume the true mean and SD are known. Limits set from a 20-run baseline have an SD that's off by up to about 30%, which raises real false rejections. Use more baseline runs, or treat these numbers as a best case. The rule settings (1-2s and 4-1s as warnings, R-4s off) are choices, not standards.

Agent data often breaks this. Counts like steps can be nearly constant, and some outputs split into two groups (clean runs vs. runs with a retry). If yours is counts or pass/fail, use the count limits below instead. If it's a number, look at a histogram of your baseline first: one hump means these numbers roughly hold, two humps or a spike means they don't.

Count limits, for pass/fail and rates

For anything counted: failed runs, process errors, never-events. Chart the number of failures in each block of runs against limits from the binomial distribution. Blocks don't overlap: a rolling window that slides one run at a time fires far more often than these rates.
