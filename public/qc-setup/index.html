Agent QC Setup

Laboratories keep a test trustworthy with nine kinds of quality control. This setup maps each one to a clinical AI agent and gives every set point a starting value, so a team that changes nothing still has a defensible plan. Each value is adjusted at validation. Explanations sit underneath each measure, closed until you want them.

The map: nine measures

Knob 1 · Metrics. What to measure for each question.
Knob 2 · Rules and limits. Which alert rules fit the data's shape.
Knob 3 · Lanes. What counts as acceptable, set clinically, including required behaviors.
Knob 4 · Response. What happens when a knob trips: hold, lookback, release.

What cannot be done cheaply: showing that a failure rate is very low takes reviewer time, however cheap the runs are. Runs cost little for AI; clinical review, lane setting, and labeling are the real costs.

Knob 3 · Lanes · Set here

Lanes: what counts as acceptable, per control

A lane is the range of answers clinicians accept for one control. It is set before any runs, from intended use, not from what the agent happens to do. Lanes feed Allowable error (measure 3) and Escalation (measure 6).

Answer scale, most urgent first

DescriptorThe ordered answers the agent can give, one per line, most urgent at the top. An answer below the lane is slower than acceptable (undertriage); above it is faster (overtriage). Starting value: six levels modeled on the disposition tiers common in US nurse telephone triage (Schmitt-Thompson style). Best alignment: use the exact levels and lanes of the triage protocol your nurse line already licenses, so the agent is held to the same standard as the nurses.

Lanes approved by

DescriptorLanes are a clinical decision. The approver signs the full set at validation, and again whenever a lane changes.

Strip key: green in the lane · red would be rejected · amber would warn · grey accepted.

Worked example and common mistake

The starting controls are an illustrative nurse-line triage set, not clinical guidance: replace them with your own, written and approved by your clinicians. Two are anchored to public guidance (heart-attack and AWHONN POST-BIRTH warning signs); the other two have no public anchor and should follow your own protocol. They show the pattern: the lane is asymmetric because the cost of error is. Sending a stable caller to the ED wastes a visit; keeping a caller with chest pain at home can kill.

Common mistake: a lane of exactly one answer for a case where clinicians would reasonably disagree. Every reasonable variation then reads as agent error, and the false alarms train people to ignore the chart.
